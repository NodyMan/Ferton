# FERTON.uz — Autoclaved Aerated Concrete Factory Landing Page

**Live preview:** [ferton-uz.netlify.app](https://ferton-uz.netlify.app/)

A marketing landing page for **FERTON**, an autoclaved aerated concrete ("gazobeton") block manufacturer based in the Farg'ona region, Toshloq district, Uzbekistan, produced by **"Vodiy Marhabo" MCHJ**.

> **Note:** This is a preview build. The full production site includes factory video footage in place of the image slideshow shown here.

## About

FERTON produces autoclaved gas concrete wall blocks manufactured to **GOST 31360-2024** standard. The site is built to inform potential customers (builders, contractors, homeowners) about the product's technical advantages over traditional brick and to drive phone contact/leads.
